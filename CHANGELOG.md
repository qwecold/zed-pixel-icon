# Changelog

## 0.1.0 — 2026-11-15

- Initial release.
- Ported the Jerry's Pixel Icons catalog to Zed's icon theme format
  (schema v0.3.0).
- 88 file icons, 51 folder icon pairs, 145 file names, 124 suffixes and
  160 folder name matches (including capitalized spellings).
- Added extra associations for common config files such as `Cargo.toml`,
  `pyproject.toml`, `requirements.txt`, `compose.yaml` and modern
  Vite/Tailwind/Vitest/ESLint config variants.
